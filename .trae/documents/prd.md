## 1. 产品概述

大型户外共享电单车平台的车辆监管与智能运维系统，面向城市共享电单车运营场景，整合车辆调度、智能运维、用户骑行、数据运营四大核心能力。系统通过实时定位、电量监控、电子围栏、信用体系、动态计价等技术手段，实现车辆全生命周期管理，提升运营效率和用户体验。

- 解决共享电单车运营中车辆分散、调度低效、故障处理慢、计价不灵活等痛点
- 面向城市共享出行运营商，提供一站式智能运维与运营管理平台

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 手机号注册 | 扫码开锁、骑行、还车、故障举报、查看骑行记录和费用 |
| 运维人员 | 管理员分配账号 | 查看待处理任务、查看换电路线、扫码确认任务、更新电池状态 |
| 区域主管 | 管理员分配账号 | 查看区域热力图、车辆分布、周转率/故障率统计、调整调度优先级 |
| 平台管理员 | 系统预设账号 | 设置分时段计价规则、天气调价、查看运营报告、管理用户和运维人员 |

### 2.2 功能模块

1. **登录页面**：角色选择、账号密码登录
2. **用户首页**：地图找车、附近车辆推荐、扫码开锁
3. **骑行中页面**：实时位置追踪、动态计费显示、还车操作
4. **用户中心**：骑行记录、费用明细、信用分、故障举报
5. **运维工作台**：任务列表、换电路线地图、扫码确认
6. **区域主管大屏**：车辆分布热力图、周转率/故障率图表、调度优先级调整
7. **管理员后台**：计价规则管理、天气调价配置、运营报告、用户管理
8. **消息中心**：实时通知提醒、消息详情、凭证下载

## 3. 核心流程

### 3.1 用户骑行流程

用户打开App → 地图显示附近可用车辆 → 系统根据定位+电量推荐最近车辆 → 用户扫码开锁 → 系统检查信用分 → 信用分低于阈值则需缴纳押金 → 解锁成功 → 骑行中每30秒上报位置 → 用户点击还车 → 判断是否在电子围栏内 → 围栏内正常还车 → 围栏外加收调度费并扣信用分 → 按动态计价规则计算费用 → 自动扣款 → 推送还车消息

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝绿色 (#0F766E) 作为品牌色，传达科技感和环保理念；活力橙 (#F97316) 作为强调色，用于关键操作和告警
- **辅助色**：深灰 (#18181B) 用于文字，浅灰 (#F4F4F5) 用于背景，白 (#FFFFFF) 用于卡片
- **按钮风格**：圆角矩形（8px），主按钮实色填充，次按钮描边，告警按钮橙色
- **字体**：标题使用 DM Sans（粗体），正文使用 Noto Sans SC（常规），数字使用 JetBrains Mono
- **布局风格**：侧边导航+内容区域，卡片式布局，数据大屏全屏展示
- **图标风格**：线性图标，2px 描边，与 lucide-react 图标库风格一致
- **动效**：页面切换淡入，卡片悬停微上浮，数据图表渐入动画，告警脉冲动画

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 区域主管大屏和管理员后台适配 1920×1080 大屏
- 用户端和运维端适配平板横屏 (1024×768)
- 触控优化：按钮最小点击区域 44×44px，地图手势操作支持
